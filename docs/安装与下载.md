# 安装、下载与升级

## 官方入口与状态

[GitHub Releases](https://github.com/xz2888/stock-traffic-light-releases/releases) 是本仓库成果入口。文档建立时公开 APK 尚未上传；没有实际 APK 附件的条目不算可下载版本。不要使用名称相似的第三方打包文件。

每日观察 PDF 请看 [资料入口](https://github.com/xz2888/stock-traffic-light-releases/releases?q=daily-observation&expanded=true)。阅读前核对数据日期、生成日期和资料说明；未发布、延迟或生成失败不能解读为空名单。公开资料不应包含任何人的真实持仓、账号或交易记录。

## 安装步骤（取得正式 APK 后）

1. 系统要求 Android 8.0 / API 26 或以上；兼容性还受厂商系统及 Web/网络环境影响。
2. 从正式 Release 下载 APK，核对发布者、版本、文件大小和 SHA256。不要把来源不明的 APK 当作官方更新。
3. 在系统安装器中检查应用名称。系统可能要求为当前下载/文件管理应用开启“安装未知应用”；仅对可信来源临时授权，完成后可撤回。
4. 首次启动到“悬浮窗设置”授权显示在其他应用上层，再返回点击“启动悬浮窗”。不需要浮窗时点“停止悬浮窗”或通知中的停止按钮。
5. 新安装没有个人股票，先添加观察卡。记录持仓时必须输入实际成交信息，不使用虚构示例代替真实账本。

## 覆盖升级与数据保护

- 已有用户应使用同包名、同签名的正式新版覆盖安装。**不要先卸载，不要清除应用数据**，本机交易档案可能因此永久丢失。
- 应用内“检查更新”需服务可用；发现新版先展示版本与变更，确认后才下载并交系统安装，不静默安装。
- 安装完成可能需要点击系统“打开”或桌面图标，不保证自动重启。
- 启动失败时优先联系作者，保留版本与错误信息；不要自行降级、换签名或重置数据。
- 本仓库未启用自动构建/自动 APK 发布，不提供调试包作为正式下载。
