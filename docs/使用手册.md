# 盯盘红绿灯使用手册

适用依据：1.9 / code55 已冻结发行说明与应用手册。这里介绍操作，不把开发候选功能当作已发布功能。

## 1. 开始与停止浮窗

在“悬浮窗设置”允许上层显示，回到应用点击“启动悬浮窗”。点击“停止悬浮窗”或常驻通知的停止按钮关闭。系统撤销权限、省电或清理后台都可能中断显示；不保证锁屏可用。

点按圆点/方框展开，拖动调整位置。展开列表可短滑动滚动、轻点收起、长按后拖动。停止触摸后会自动收起。红涨、绿跌、白平，灰色表示不可用或过期；颜色和趋势箭头不是买卖指令。

展开列表按持仓、指数、用户观察、推荐观察组织，空组不占位；同一股票优先展示持仓，其次用户观察、推荐观察。个股“显示”开关只控制浮窗，不删除记录或改变收益。

## 2. 添加观察股和记录交易

1. 输入 A 股六位代码或名称，核对目录查询结果、市场与证券身份。不能靠代码首位猜市场；目前编辑器不支持新增港美个股。
2. 可保存零股观察卡，它不参与账户收益。
3. 记录实际买卖时，在“仓位变化 ＋买/-卖”输入正数买入或负数卖出，并填写真实成交价。卖出不得超过持股。
4. 点击本股“保存”，核对方向、数量、价格、前后股数，再确认。取消不入账；这只是记录，不向券商发单。

当前股数与平均成本由已确认流水计算，不直接手改。一次保存只处理本卡，不提交其他卡草稿。排序输入目标名次后点“排序”，立即保存顺序，不提交交易。草稿不是已保存资料。

“持仓变化”查看本股记录；期初基线不是一次买卖。删除已保存卡需确认，隐藏卡片不等于卖出；未平仓记录与历史收益仍在档案中，可从收益详情恢复已移除卡片。不要用删除来模拟清仓。

## 3. 本金与收益

在“账户本金”明确选择“本金转入/本金转出”，核对金额及前后本金后确认。普通买卖、行情刷新不会自动增减本金。当前本金＝期初本金＋累计转入－累计转出；本金不等于券商可用现金。

- 平均成本：买入后按原成本与新买支出加权；部分卖出不改变剩余均价。
- 个股累计收益：当前市值＋已记录卖出收入－后续买入支出－初始持仓成本。
- 个股收益率：累计收益÷有记录支持的累计投入；投入包含初始持仓成本及后续买入支出，不减卖出回款。
- 今日收益：当前市值－期初持股×昨收＋当日卖出收入－当日买入支出。
- 账户合计收益率沿用账户已确认统计口径，以账户累计收益除以当前本金；已确认的固定历史盈利偏移不重复扣减，不分摊到个股。
- 阶段收益使用相邻本金变动边界的累计收益差，不把转入、转出金额或市值差当利润。

本金为零或未知，百分比不适用；缺行情、成本或可靠起止快照时显示未知/待核算，不填零。纯观察不计收益；曾持仓但已清仓、隐藏的记录仍保留历史。

周/月/年初始化采用已保存的账面起点口径，首次期间可能承接累计收益，不代表该期间真实买入；跨期间后依赖可靠边界估值和现金流。历史缺失不能凭空补齐，迁移日期不等于真实成交日期。未录入的手续费、税费、分红不计入结果，请勿直接当作券商对账单。

## 4. 推荐观察与每日 PDF

推荐观察与用户观察独立保存，不写持仓、成本、交易或本金。可点“同步推荐观察”立即读取；正常打开应用也会后台补读。北京时间18点后的系统调度受休眠、强制停止和省电影响，不承诺准点执行。

检查名单行情日期、最后成功同步时间和失败提示。失败/过期响应保留旧缓存，不表示当天没有结果。“显示推荐观察”关闭只隐藏展示，不停同步、不删除数据。

[每日 PDF 入口](https://github.com/xz2888/stock-traffic-light-releases/releases?q=daily-observation&expanded=true) 是公开阅读资料，不能替代应用内同步成功的证据。未出现正式附件时尚未开放；观察仅供研究，不是收益保证。

## 5. 公共设置与提醒

勾选项自动保存；有效数字停止输入后保存，不必保存股票，也不会提交个股交易。行情刷新可配置，网络成功不等于实时。急涨急跌提醒比较短时价格变化，非全天涨跌幅，受采样、冷却、静音、勿扰及音量影响。

## 6. 服务、隐私和排错

行情、推荐观察、更新与授权分别依赖网络服务，不保证持续可用。先核对网络、数据时间、应用版本和权限；不要因收益暂未取得就认为收益为零。应用手册记录有试用及可免费续期机制，不强制付费，不应把任何捐赠说成保证盈利或购买荐股服务。

拒绝可选匿名统计不影响本地使用及相关续期/更新操作；必要的服务请求仍可能处理随机安装标识与网络信息，详见[隐私与权限](隐私与权限.md)。公开反馈请遮盖个人资料。
