# 隐私与权限

适用依据：1.9 / code55 应用声明与手册。本页是功能说明，不将“本地账本”等同于完全不联网或不处理个人信息。

## 数据与服务

- 持仓数量、成本、交易流水、收益档案和设置保存于手机本地；应用说明不将这些账本字段随行情或可选统计请求上传。
- 股票名称/代码查询及行情请求会到达相应行情提供者；查询输入与证券代码可能被该服务处理，网络接入方可看到IP及访问时间。
- 同意可选匿名统计后记录同意版本、使用版本和北京时间活跃日期，不是自然人数统计。可以拒绝或撤回；手册约定撤回停止采集并清空待发统计，联网后删除对应服务端统计。
- 下载、安装关联或兑换等必要服务可能使用随机安装ID和恢复凭证，不以同意可选统计为前提。不要公开这些凭证。
- 手册约定服务端日活及支持意向保留90天、待发统计最多7天；此为产品说明，不代表本次对所有在线服务重新做了合规审计。
- 应用提供自愿支持入口，支付由用户在支付应用确认；公开仓库不提供支付二维码，不处理支付凭据。

## Android Manifest 声明的权限

| 权限 | 用途与控制 |
| --- | --- |
| SYSTEM_ALERT_WINDOW | 用户授权后显示浮窗，可随时停止或撤销。 |
| INTERNET | 行情、目录查询、推荐名单、更新及相关服务。 |
| ACCESS_NETWORK_STATE | 判断联网状态。 |
| FOREGROUND_SERVICE / FOREGROUND_SERVICE_SPECIAL_USE | 支持用户主动开启的悬浮显示前台服务与通知。 |
| REQUEST_INSTALL_PACKAGES | 更新校验后请求系统安装；需用户授权确认，不静默安装。 |
| RECEIVE_BOOT_COMPLETED | 清单声明包含此项；不能仅凭声明承诺开机自动显示或绕过后台限制。 |

该版清单未声明定位、相机、麦克风、联系人或外部存储读取权限。系统/厂商实际提示以设备为准。备份开关关闭，**不要依赖系统自动备份恢复账本**；卸载或清除数据可能丢失记录。
